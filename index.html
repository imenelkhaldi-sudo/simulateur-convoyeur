Aide — SITRAIN Simulator Web v1.0

Application Sitrain Simulator

Cette application simule un convoyeur industriel Siemens pour la formation SITRAIN.

Fonctionnalités :

  • Convoyeur : Visualisation du tapis avec capteurs, pièces et voyants
  • Panneau de contrôle : Interrupteurs (I0.0-I0.7), LEDs (Q0.0-Q0.7), curseurs analogiques
  • Connexion PLC : Mode simulation locale ou connexion via WebSocket à un PLC réel/PLCSim
  • Exercices : Sélection d'exercices SITRAIN (TIA-PRO1, TIA-PRO2, etc.)

Raccourcis clavier :

  • Espace : Placer une pièce
  • V : Table des variables
  • Echap : Fermer les fenêtres
